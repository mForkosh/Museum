# Landing Page for NAMU

This is a pet project — a one-page website inspired by a design concept for the National Art Museum of Ukraine (NAMU). The project was created for practice and portfolio purposes.

## 🔧 Technologies

- **HTML** — page structure
- **SASS (SCSS)** — styling using variables and nesting
- **BEM** — class naming methodology
- **JavaScript** — used to control the slider

## 📱 Responsiveness

The page adapts to various screen sizes: mobile devices, tablets, and desktops.

## 🖼️ Slider

The gallery uses CSS `scroll-snap` for smooth scrolling. JavaScript adds the following functionality:

- **Dots** that indicate the active slide
- **Clicking a dot** scrolls to the corresponding slide
- **Automatic update of active dot** during manual scrolling
