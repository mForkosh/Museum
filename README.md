# Landing Page для NAMU

Це пет-проєкт — односторінкова сторінка, створена за мотивами дизайну для Національного художнього музею України (NAMU). Проєкт реалізовано для практики та портфоліо.

## 🔧 Технології

- **HTML** — структура сторінки
- **SASS (SCSS)** — стилізація з використанням змінних і вкладеності
- **BEM** — методологія іменування класів
- **JavaScript** — для керування слайдером

## 📱 Адаптивність

Сторінка адаптується під різні розміри екранів: мобільні пристрої, планшети, десктопи.

## 🖼️ Слайдер

Використано CSS scroll-snap для прокручування галереї. За допомогою JavaScript реалізовано:

- **Доти (точки)**, які відображають активний слайд
- **Клік по точці** — переходить до відповідного слайду
- **Автоматичне оновлення активної точки** при ручній прокрутці
